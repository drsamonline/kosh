What it does

OptimisePNG, GZIP, ZIP and JPEG re-compressed losslessly. Zopfli where it pays, zlib -9 where it does not — and it says which.
PackA verified container: table of contents, per-entry SHA-256, a manifest digest, four codecs, parallel blocks.
SplitParts with a manifest. Joining checks every part and the whole file before it writes the result.
VerifyProve an artefact is intact without extracting it. Structure, hashes, block bounds.

Measured, not claimed

Fixed corpus, seed 20261111, same bytes to every codec. Reproduce with kosh bench. Full tables and speeds in FINDINGS.md.

Brotli wins on records and logs; xz wins on prose by 1.4%. Kosh is a container and a codec choice, not a new entropy coder — when the last percent matters, that is ziptastic's job.

Install

$ pip install -e .
$ kosh doctor          # checks every codec with a live round-trip
$ kosh ui              # http://127.0.0.1:8765

Python 3.10+, wheels on Linux, macOS and Windows. No account, no network, no telemetry.

Kosh does not implement BWT, rANS or PPMd. Where a CHCE engine is installed, kosh pack --engine ziptastic spawns it: a process boundary, never a link.
